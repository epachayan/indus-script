# Marshall (1931) vol. II, "Mohenjo-daro: Tabulation of Seals" (pp. 402-405)
## Hand transcription

Source: Internet Archive item in.ernet.dli.2015.107493 (out of copyright), PDF pages
56-59 = printed pages 402-405. Two columns per page; file names follow the printed page
and column (p402L = page 402, left column).

Columns as printed: plate no. | size in inches | level below SURFACE (ft, in) | type |
material and colour (ticks under Steatite / Faience / Pottery) | site and serial no.

Conventions
- `level_ft` = `surface` where the table prints "Sur."; blank where it prints a dash.
- `?` in a size where the table prints `?`; blank row values where the table prints a dash.
- Material is given as the ticked column (Steatite unless stated).
- `area` is the excavation area of the serial number (HR, VS, DK, C, E, SD, L, B, BJ, D,
  DM, F); Marshall does NOT give block/house/room here, unlike Mackay 1938.

Not comparable with Mackay
- Marshall measures depth below the modern ground surface; Mackay measures from a fixed
  datum. The two depth columns must not be pooled.
- Locus resolution differs (area only vs block/house/room).

  worth rechecking against the page.
